# Оптимизатор Windows 11

Скрипт с меню для MSI Z490 / i5-10600KF / RTX 3060 Ti.

Запуск: двойной клик по `run.bat` (права администратора скрипт запросит сам).

Все изменения сохраняются в `backup.json` и откатываются пунктом 9 меню.

Какие драйверы ставить и каких версий: [DRIVERS.md](DRIVERS.md).

## Программы для установки после Windows

- [zapret-discord-youtube (Flowseal)](https://github.com/Flowseal/zapret-discord-youtube/releases/latest) — обход блокировок Discord и YouTube на Windows
- [tg-ws-proxy (Flowseal)](https://github.com/Flowseal/tg-ws-proxy/releases/latest) — локальный прокси для Telegram
- [AyuGram Desktop](https://github.com/AyuGram/AyuGramDesktop/releases/latest) — клиент Telegram с расширенными настройками
